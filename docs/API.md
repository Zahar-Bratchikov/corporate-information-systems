# HTTP API ИС УПЗ IT

Базовый префикс: **`/api`**. Авторизация: заголовок **`Authorization: Bearer &lt;JWT&gt;`**, кроме явно отмеченных анонимных методов.

Имена путей отражают назначение операции (ресурс + действие/контекст).

---

## Аутентификация

| Метод | Путь | Описание | Тело запроса |
|--------|------|----------|----------------|
| POST | `/api/authentication/login` | **Вход**: проверка логина/пароля, выдача JWT и краткого профиля | `{ "login": string, "password": string }` |
| POST | `/api/auth/login` | То же действие (алиас для совместимости со старыми сборками фронта) | то же тело |

**Ответ 200:** JSON с полями токена и пользователя (см. `LoginResponse` в backend).  
**401:** неверные учётные данные.

## Отчёты (файлы)

Все методы — **GET**, ответ — файл. Query-параметр **`format`**: `xlsx` | `docx` | `pdf` (в зависимости от отчёта).

| Путь | Описание | Параметры |
|------|----------|-----------|
| `/api/reports/it-projects-summary` | **Сводка по IT-проектам** (задачи и типы) | `format=xlsx` \| `pdf` |
| `/api/reports/tasks-by-assignee` | **Задачи исполнителя** + итоговая строка | `assigneeId` (обяз.), `format` |
| `/api/reports/overdue-tasks` | **Просроченные задачи** + дни просрочки | `format=xlsx` \| `pdf` |
| `/api/reports/team-assignee-workload` | **Загрузка команды** по статусам | `format=xlsx` \| `docx`, опционально `sprintId` |
| `/api/reports/it-projects-status-overview` | **Статусы по проектам** (выполнено, в работе, просрочено, %) | `format=docx` \| `pdf` |

## Автотесты UI

Во фронтенде на ключевых элементах заданы **`data-testid`** с префиксом `upzit-` (см. исходники страниц). Дополнительно используются классы **`upzit-*`** рядом с существующими стилевыми классами.

Константы URL на стороне клиента: **`frontend/src/api/endpoints.ts`**.
